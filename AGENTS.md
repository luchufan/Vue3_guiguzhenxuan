# AGENTS

## Commands

- Single npm package; no workspace/test runner. Requires Node `^22.18.0 || >=24.12.0`.
- `npm run dev` starts Vite; `npm run type-check` = `vue-tsc --build`; `npm run build` runs type-check and `vite build` in parallel; `npm run build-only` skips type-check.
- No lint/test scripts. ESLint config exists but is not a gate; `npx eslint .` also scans `dist` and reports many pre-existing errors. Verify with `npm run type-check` / `npm run build`.

## App wiring

- Entry: `index.html` -> `src/main.ts`. Pinia singleton lives in `src/stores/index.ts`; `src/router/index.ts` imports it directly, so use that same instance when creating stores outside components.
- `src/router/routers.ts` is the only route table. The sidebar renders from `userInfo.menuRouters`, which is copied from it; route `meta.title`, `meta.hidden`, and `meta.icon` drive menu labels/visibility and document title.
- `src/router/index.ts` redirects unauthenticated routes to `/login`. Auth uses local storage key `TOKEN` and header `token`; new protected routes need no guard changes, public routes do.

## API and mocks

- API modules follow `src/api/<domain>/<resource>/{index.ts,type.ts}`. `src/utils/request.ts` sets `baseURL: '/api'`, adds the `token` header, and returns `response.data`; call APIs with paths that omit `/api` and use `request.get<any, ResponseType>`.
- Vite mocks are always enabled (`enable: true`). Files in `mock/` define full `/api/...` URLs; other `/api` requests proxy to `http://localhost:10086` with the `/api` prefix stripped.

## Generated/global tooling

- `auto-imports.d.ts` and `components.d.ts` at the repo root are generated by unplugin plugins and tracked; don't hand-edit them.
- Element Plus components and `ElMessage` are auto-imported; all Element Plus icons are registered globally by name, including for route `meta.icon`.
- `src/styles/variable.scss` is injected into every SCSS file via Vite; don't re-import it per component. SVG files in `src/assets/icons` are registered through `virtual:svg-icons-register` and rendered with `src/components/SvgIcons.vue`.
